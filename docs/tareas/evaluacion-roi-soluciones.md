# Tarea: Evaluar Impacto Financiero y ROI de Soluciones

## Resumen Técnico Detallado

Esta tarea se enfoca en cuantificar y analizar el impacto económico de cada solución propuesta mediante la metodología Lean–Kaizen para El Agaveño Burgers. El objetivo es proporcionar un análisis financiero riguroso que justifique la inversión en mejoras operativas y facilite la toma de decisiones gerenciales basada en datos concretos.

### Alcance de la Evaluación

La evaluación debe considerar:
- **Costos de implementación**: Inversión inicial requerida
- **Ahorros directos**: Reducción de costos operativos
- **Ingresos incrementales**: Aumento de ventas o producción
- **Beneficios indirectos**: Mejora de reputación, retención de clientes
- **Período de recuperación**: Tiempo estimado para recuperar la inversión
- **Retorno de inversión (ROI)**: Porcentaje de ganancia neta

## Rutas Principales Incluidas

### 1. **Ruta de Análisis de Costos Operativos**
```
Identificación de costos actuales
    ↓
Desglose por categoría (labor, insumos, energía, etc.)
    ↓
Proyección de costos con soluciones implementadas
    ↓
Cálculo de ahorros potenciales
```

### 2. **Ruta de Análisis de Eficiencia Operativa**
```
Medición de tiempos base (situación actual)
    ↓
Proyección de tiempos con nuevos procesos
    ↓
Cálculo de mejora de productividad (%)
    ↓
Conversión a ahorros de mano de obra
```

### 3. **Ruta de Análisis de Ingresos**
```
Análisis de capacidad actual vs. potencial
    ↓
Estimación de aumento en volumen de pedidos
    ↓
Cálculo de ingresos adicionales
    ↓
Proyección de margen contribuyente
```

### 4. **Ruta de Análisis de Calidad y Retención**
```
Medición de defectos/errores actuales
    ↓
Proyección de mejora en satisfacción del cliente
    ↓
Estimación de retención y repetición de clientes
    ↓
Cálculo de valor de cliente de por vida (LTV)
```

### 5. **Ruta de Cálculo de ROI Consolidado**
```
Cálculo de beneficios totales
    ↓
Cálculo de inversión total
    ↓
Determinación de período de recuperación
    ↓
Cálculo de ROI y VAN
    ↓
Análisis de sensibilidad
```

**1.3 Documentar procesos actuales y métricas base**
- Tiempo promedio de servicio por pedido
- Capacidad de producción actual
- Tasa de errores/devoluciones
- Costo unitario de operación

### Fase 2: Análisis de Costos Actuales (Semana 2-3)

**2.1 Desglosar costos por categoría**
```
Estructura de costos actual:
├── Mano de obra directa
│   ├── Preparación
│   ├── Cocina
│   └── Servicio
├── Insumos (ingredientes)
├── Suministros (empaques, etc.)
├── Servicios (energía, agua, etc.)
├── Mantenimiento y equipo
└── Otros costos operativos
```

**2.2 Calcular costo unitario por proceso**
- Costo por pedido procesado
- Costo por hora de operación
- Costo por unidad de producto

**2.3 Identificar oportunidades de ahorro**
- Procesos con mayor desperdicio
- Cuellos de botella costosos
- Ineficiencias detectadas en diagnóstico

### Fase 3: Modelado de Soluciones (Semana 3-4)

**3.1 Para cada solución propuesta, calcular:**

**a) Inversión Inicial (Capex)**
```
Inversión = Costo de capacitación + Costo de software/herramientas 
            + Costo de rediseño de procesos + Contingencia (10-15%)
```

**b) Ahorros Anuales (Opex)**
```
Ahorro de Mano de Obra = (Tiempo ahorrado por pedido) × (Volumen anual) 
                          × (Costo hora)

Ahorro de Insumos = (% de desperdicio reducido) × (Costo anual de insumos)

Ahorro de Otros = Energía, suministros, etc.

Total Ahorros Anuales = Suma de todos los ahorros
```

**c) Ingresos Incrementales**
```
Ingresos Adicionales = (Aumento de capacidad) × (Precio promedio de venta)
                       × (Días operativos anuales)
```

**3.2 Crear escenarios de proyección**
- Escenario conservador (60% del beneficio estimado)
- Escenario realista (100% del beneficio estimado)
- Escenario optimista (140% del beneficio estimado)

### Fase 4: Cálculo de Métricas Financieras (Semana 4)

**4.1 Período de Recuperación de Inversión (Payback)**
```
Payback (años) = Inversión Inicial / Beneficio Neto Anual

Ej: $10,000 inversión / $5,000 beneficio anual = 2 años
```

**4.2 Retorno sobre Inversión (ROI)**
```
ROI (%) = [(Beneficios Totales - Inversión Inicial) / Inversión Inicial] × 100

Ej: [($15,000 - $10,000) / $10,000] × 100 = 50% ROI
```

**4.3 Valor Presente Neto (VAN)**
```
VAN = Σ [Beneficio Neto Año n / (1 + Tasa Descuento)^n] - Inversión Inicial

Usar tasa de descuento = 10-15% (costo de capital típico)
```

**4.4 Tasa Interna de Retorno (TIR)**
```
TIR = Tasa de descuento donde VAN = 0

Indica el retorno anual esperado de la inversión
```

### Fase 5: Análisis de Sensibilidad (Semana 4-5)

**5.1 Identificar variables críticas**
- Costo de mano de obra
- Volumen de pedidos
- Duración de la implementación
- Tasa de adopción del personal

**5.2 Crear tabla de sensibilidad**

**5.3 Evaluar puntos de equilibrio**
- ¿Qué volumen mínimo justifica la inversión?
- ¿Qué incremento de costos sigue siendo rentable?

### Python: Cálculo de ROI y Métricas Financieras

```python
# evaluador_roi.py
class EvaluadorROI:
    """Evalúa el impacto financiero y ROI de soluciones Lean-Kaizen"""
    
    def __init__(self, tasa_descuento=0.10):
        """
        Args:
            tasa_descuento: Tasa de descuento para cálculos VAN/TIR (default 10%)
        """
        self.tasa_descuento = tasa_descuento
        self.soluciones = {}
    
    def registrar_solucion(self, nombre, inversion_inicial, 
                          ahorros_anuales, ingresos_incrementales, 
                          anos_proyeccion=5):
        """
        Registra una solución para análisis financiero
        
        Args:
            nombre: Nombre de la solución
            inversion_inicial: Monto de inversión inicial en $
            ahorros_anuales: Lista de ahorros esperados por año
            ingresos_incrementales: Lista de ingresos incrementales por año
            anos_proyeccion: Años de proyección (default 5)
        """
        self.soluciones[nombre] = {
            'inversion_inicial': inversion_inicial,
            'ahorros_anuales': ahorros_anuales,
            'ingresos_incrementales': ingresos_incrementales,
            'anos_proyeccion': anos_proyeccion
        }
    
    def calcular_payback(self, nombre):
        """Calcula el período de recuperación de inversión (en años)"""
        sol = self.soluciones[nombre]
        beneficio_neto_anual = (sol['ahorros_anuales'][0] + 
                               sol['ingresos_incrementales'][0])
        
        if beneficio_neto_anual <= 0:
            return float('inf')
        
        payback = sol['inversion_inicial'] / beneficio_neto_anual
        return round(payback, 2)
    
    def calcular_roi(self, nombre):
        """Calcula el Retorno sobre Inversión (ROI) en porcentaje"""
        sol = self.soluciones[nombre]
        
        # Suma de beneficios totales a lo largo del período
        beneficios_totales = sum(
            (sol['ahorros_anuales'][i] + sol['ingresos_incrementales'][i])
            for i in range(len(sol['ahorros_anuales']))
        )
        
        roi = ((beneficios_totales - sol['inversion_inicial']) / 
               sol['inversion_inicial']) * 100
        
        return round(roi, 2)
    
    def calcular_van(self, nombre):
        """Calcula el Valor Presente Neto (VAN)"""
        sol = self.soluciones[nombre]
        van = -sol['inversion_inicial']
        
        for año in range(1, sol['anos_proyeccion'] + 1):
            idx = min(año - 1, len(sol['ahorros_anuales']) - 1)
            flujo_neto = (sol['ahorros_anuales'][idx] + 
                         sol['ingresos_incrementales'][idx])
            van += flujo_neto / ((1 + self.tasa_descuento) ** año)
        
        return round(van, 2)
    
    def calcular_tir(self, nombre, precision=0.001):
        """Calcula la Tasa Interna de Retorno (TIR) por iteración"""
        sol = self.soluciones[nombre]
        
        def calcular_van_a_tasa(tasa):
            van = -sol['inversion_inicial']
            for año in range(1, sol['anos_proyeccion'] + 1):
                idx = min(año - 1, len(sol['ahorros_anuales']) - 1)
                flujo_neto = (sol['ahorros_anuales'][idx] + 
                             sol['ingresos_incrementales'][idx])
                van += flujo_neto / ((1 + tasa) ** año)
            return van
        
        # Búsqueda binaria de la TIR
        tasa_baja, tasa_alta = 0.0, 1.0
        
        while tasa_alta - tasa_baja > precision:
            tasa_media = (tasa_baja + tasa_alta) / 2
            if calcular_van_a_tasa(tasa_media) > 0:
                tasa_baja = tasa_media
            else:
                tasa_alta = tasa_media
        
        return round((tasa_baja + tasa_alta) / 2 * 100, 2)
    
    def generar_reporte(self, nombre):
        """Genera un reporte completo de métricas financieras"""
        return {
            'Solución': nombre,
            'Inversión Inicial ($)': self.soluciones[nombre]['inversion_inicial'],
            'ROI (%)': self.calcular_roi(nombre),
            'Payback (años)': self.calcular_payback(nombre),
            'VAN ($)': self.calcular_van(nombre),
            'TIR (%)': self.calcular_tir(nombre),
            'Decisión': 'RECOMENDADO' if self.calcular_roi(nombre) > 20 else 'EVALUAR'
        }


# Ejemplo de uso
if __name__ == "__main__":
    evaluador = EvaluadorROI()
    
    # Solución 1: Optimización de Cocina
    evaluador.registrar_solucion(
        nombre="Optimización de Procesos de Cocina",
        inversion_inicial=5000,
        ahorros_anuales=[2000, 2200, 2400, 2600, 2800],
        ingresos_incrementales=[1000, 1500, 2000, 2500, 3000]
    )
    
    # Solución 2: Sistema de Gestión de Pedidos

        nombre="Sistema de Gestión de Pedidos",
        inversion_inicial=8000,
        ahorros_anuales=[1500, 1800, 2100, 2400, 2700],
        ingresos_incrementales=[2000, 2500, 3000, 3500, 4000]
    )
    
    # Generar reportes
    for nombre in evaluador.soluciones.keys():
        print("\n" + "="*60)
        reporte = evaluador.generar_reporte(nombre)
        for metrica, valor in reporte.items():
            print(f"{metrica}: {valor}")
```

### SQL: Estructura de Base de Datos para Datos Financieros

```sql
-- crear_tablas_financieras.sql

-- Tabla de Costos Actuales
CREATE TABLE costos_operativos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    categoria VARCHAR(100) NOT NULL,
    subcategoria VARCHAR(100),
    costo_mensual DECIMAL(10, 2),
    unidad_medida VARCHAR(50),
    fecha_registro DATE DEFAULT CURRENT_DATE,
    observaciones TEXT
);

-- Tabla de Soluciones y su Impacto
CREATE TABLE soluciones_evaluadas (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre_solucion VARCHAR(200) NOT NULL,
    descripcion TEXT,
    inversion_inicial DECIMAL(12, 2),
    ahorro_anual_estimado DECIMAL(12, 2),
    ingresos_incrementales DECIMAL(12, 2),
    payback_anos DECIMAL(5, 2),
    roi_porcentaje DECIMAL(5, 2),
    van_5anos DECIMAL(12, 2),
    tir_porcentaje DECIMAL(5, 2),
    prioridad INT,
    estado VARCHAR(20),
    fecha_evaluacion DATE DEFAULT CURRENT_DATE
);

-- Tabla de Análisis de Sensibilidad
CREATE TABLE analisis_sensibilidad (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_solucion INT,
    variable_critica VARCHAR(100),
    escenario VARCHAR(50), -- 'Pesimista', 'Realista', 'Optimista'
    variacion_porcentaje DECIMAL(5, 2),
    roi_resultado DECIMAL(5, 2),
    van_resultado DECIMAL(12, 2),
    FOREIGN KEY (id_solucion) REFERENCES soluciones_evaluadas(id)
);

-- Tabla de Beneficios Detallados por Solución
CREATE TABLE beneficios_soluciones (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_solucion INT,
    tipo_beneficio VARCHAR(100), -- 'Ahorro Mano de Obra', 'Ahorro Insumos', etc.
    ano INT,
    monto_beneficio DECIMAL(12, 2),
    descripcion TEXT,
    FOREIGN KEY (id_solucion) REFERENCES soluciones_evaluadas(id)
);
```
